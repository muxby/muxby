## What I build

My repositories cover applied AI, privacy-preserving learning, distributed systems, operational dashboards, immersive web products, desktop and mobile utilities, systems programming, simulation, and data analysis. The common thread is turning a difficult technical problem into a system that people can understand, operate, and improve.

## Selected work

| Repository | Focus |
|---|---|
| [AEGIS Cyber Defense](https://github.com/muxby/AEGIS_Cyber-Defense) | LLM-assisted security operations, telemetry analysis, threat detection, and incident explanation. |
| [FedVault Privacy](https://github.com/muxby/FEDVAULT-PRIVACY) | Federated learning with differential privacy, secure aggregation, and a real-time dashboard. |

## How I work

I prefer small, testable systems with explicit boundaries. I care about the interface, the service contract, the data model, and the operational story as one connected design problem. The strongest projects in this portfolio move between research and implementation: an algorithm becomes a product surface, a systems concept becomes a working service, and a visual experiment becomes a tool someone can use.
